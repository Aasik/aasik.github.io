Teaching

I teach computing and IT at the Faculty of Computing, International Campus of Science and Technology (ICST), and run independent ICT classes alongside it. Below are the modules I teach and how I approach them.

Current Teaching: ICST, Faculty of Computing

  • HDIT 11034: Principles of Computer Programming (Pearson BTEC Level 4). Programming fundamentals in Python: algorithms, flowcharts and pseudocode, control structures, functions, data structures, debugging, coding standards and an introduction to OOP and database programming.
  • HDIT 21183: Artificial Intelligence and Machine Learning (Pearson BTEC Level 4). Foundations of AI, core ML algorithms (linear and logistic regression, KNN), computer vision, NLP, deployment, and the ethical challenges of intelligent systems.
  • HDIT 21202: Project Proposal Writing (Lecturer-in-Charge). Guiding Higher Diploma students through preparing structured IT project proposals that feed into the following semester's project.
  • Systems Analysis and Design (Pearson BTEC). Turning a real business problem into a well-planned information system, from requirements gathering and feasibility study to modelling with use case, data flow and entity relationship diagrams.

Other Teaching

  • CIT338: Basic Concepts for Data Visualization. Python for data work, data types and APIs, cloud vs on-premise, and Power BI.
  • G.C.E. Advanced Level ICT (independent tuition). Classes following the Sri Lankan A/L syllabus, with bilingual (Tamil and English) notes and exercises.

Teaching Approach and Materials

  • Lecture slides, practical lab sheets, quizzes, debugging worksheets, mini-project guidelines and rubrics, written for each session and aligned to the module learning outcomes.
  • Hands-on, Python-first practice: students predict output, fix buggy code and build small projects rather than only reading about concepts.
  • Industry experience in infrastructure and IT support is brought into the classroom so theory is connected to real-world practice.

Teaching Interests

  • Programming fundamentals, Artificial Intelligence and Machine Learning, Explainable AI, Cloud Computing, Cybersecurity, Data Visualization.
